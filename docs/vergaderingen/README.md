## Historische bron

De historische vergadernotities zijn gelezen uit een lokaal Word-bestand buiten deze repository: `Vergadering Caner.docx`.

Het originele Word-bestand is niet toegevoegd aan Git en wordt niet gepubliceerd. Deze index bevat alleen een veilige samenvatting zonder echte wachtwoorden.

## Belangrijke context

Deze vergadernotities geven de afspraken en kennis van dat moment weer. Latere technische bevestigingen staan in de actuele labodocumentatie.

Een historische vergadering vermeldde bijvoorbeeld een voorlopige routeraanduiding. De actuele technische documentatie gebruikt de later bevestigde router: Cisco 1841 met hostname `R1`.

## Samenvatting

| Vergadering | Historische inhoud |
|---|---|
| Vergadering 1 | Er werd afgesproken dat het labo een personeelskant met drie switches en een klantenkant met drie switches heeft. Er werd ook gewerkt aan een Packet Tracer-topologie. |
| Vergadering 2 | De topologie werd besproken: beide kanten hebben een centrale switch met extra switches. De klantenkant bevat pc's; de personeelskant bevat een kassa, laptop en servers. PuTTY zou gebruikt worden voor switchconfiguratie. |
| Vergadering 3 | Er werd gesproken over switchbenamingen, consoletoegang, configuratie via PuTTY, ongebruikte poorten, eindtoestelhostnames, MOTD en groepsverdeling. Een vermeld wachtwoord is bewust vervangen door `<WACHTWOORD_NIET_GEPUBLICEERD>`. |
| Vergadering 4 | De algemene switchconfiguratiestappen werden besproken: initial configuration overslaan, hostname, management-IP, default gateway, console, VTY, MOTD, enable secret, wachtwoordversleuteling, controle en opslaan. |
| Vergadering 5 | Er werd genoteerd dat toestellen binnen hetzelfde subnet elkaar konden pingen. De volgende stap was routerconfiguratie. |
